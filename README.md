# naveen

A small collection of media assets (images, audio, and video) for the "REI" fan project, with no application code.

## Features
- Stored REI branding images in multiple sizes (`REI.jpg`–`REI3.jpg`).
- Fan video clip of a REI music track.
- Audio track `Vaadi-Nee-Vaadi` (MassTamilan).

## Tech Stack
- Assets only (JPG, MP3, MP4); no application code.

## Project Structure
```
├── REI.jpg, REI1.jpg, REI2.jpg, REI3.jpg  # branding images
├── REI 1280x720 ... .mp4                  # video clip
└── Vaadi-Nee-Vaadi-...mp3                 # audio track
```

## Installation
- No setup required; files are used directly as resources.

## Usage
- Reference the media from another project or simply view/play the files.
- See the related `REI` repo for the fan page that consumes these media.
